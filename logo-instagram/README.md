# Logo Scream Lab para Instagram

Logo horizontal ("screamlab" de izquierda a derecha), listo para la foto de
perfil de Instagram y para uso general en horizontal. Todo sale del vector de
mayor fidelidad (`public/brand/screamlab-logo-print.svg`), así que las curvas
son idénticas en todos los archivos, solo cambia el color y el encuadre.

## Para subir a Instagram ahora mismo

Instagram solo acepta PNG o JPG para la foto de perfil, no SVG. Sube uno de
estos dos (1080×1080 px):

- **`screamlab-instagram-perfil-fondo-negro.png`**: fondo negro, logo blanco.
  Recomendado: combina con el tema Mono que quedó por defecto en el sitio.
- **`screamlab-instagram-perfil-fondo-blanco.png`**: fondo blanco, logo negro.
  Alternativa si en algún momento se prefiere un perfil claro.

Instagram recorta la foto de perfil en círculo. Los archivos `*-vista-circular.png`
muestran cómo queda ese recorte (fondo transparente fuera del círculo): el
logo se dejó al 82% del ancho del lienzo, con margen de sobra para que
ninguna punta se corte.

## El resto de los archivos

| Archivo | Qué es |
| --- | --- |
| `screamlab-logo-horizontal-negro.svg` / `.png` | Solo el logo, negro, fondo transparente, recortado justo al diseño (3683×928 px). Para usarlo suelto en cualquier tamaño. |
| `screamlab-logo-horizontal-blanco.svg` / `.png` | Lo mismo, en blanco (para fondos oscuros). |
| `screamlab-instagram-perfil-fondo-negro.svg` | Versión editable (vector) de la foto de perfil con fondo negro. |
| `screamlab-instagram-perfil-fondo-blanco.svg` | Versión editable de la foto de perfil con fondo blanco. |
| `*-vista-circular.png` | Vista previa de cómo se ve cada versión ya recortada en círculo. Solo para revisar, no se sube a ningún lado. |

Los SVG son vectores: se pueden agrandar a cualquier tamaño (una polera, un
lienzo, una pancarta) sin perder nitidez.
